Validate provider profile files without registering them

USAGE
  openshell profile lint [OPTIONS] <--file <FILE>|--from <FROM>|--url <URL>>

FLAGS:
  -f, --file <FILE>
          Profile file to lint

      --from <FROM>
          Directory containing profile files to lint

      --url <URL>
          HTTP or HTTPS URL of one YAML or JSON profile

      --global
          Lint against platform scope (ignores --workspace)

GATEWAY FLAGS:
  -g, --gateway <GATEWAY>
          Gateway name to operate on (resolved from stored metadata)
          
          [env: OPENSHELL_GATEWAY=]

      --gateway-endpoint <GATEWAY_ENDPOINT>
          Gateway endpoint URL (e.g. <https://gateway.example.com>). Connects directly without looking up gateway metadata
          
          [env: OPENSHELL_GATEWAY_ENDPOINT=]

      --gateway-insecure
          Skip TLS certificate verification for gateway connections
          
          [env: OPENSHELL_GATEWAY_INSECURE=]

GLOBAL FLAGS:
      --workspace <WORKSPACE>
          Workspace scope for resource operations
          
          [env: OPENSHELL_WORKSPACE=]
          [default: default]

  -v, --verbose...
          Increase verbosity (-v, -vv, -vvv)

      --color <WHEN>
          When to colorize output. `auto` colorizes only when stdout is a terminal

          Possible values:
          - auto:   Colorize a stream only when that stream is a terminal and no environment override applies
          - always: Always colorize, even when output is redirected
          - never:  Never colorize
          
          [env: OPENSHELL_COLOR=]
          [default: auto]

  -h, --help
          Print help

  -V, --version
          Print version
